# Instrument DNA

素材から作る共通の楽器データ。JSON で保存し（`experiments/phase1/dna/*.dna.json`）、**同じ素材・同じシード・同じエンジンバージョンで同じ DNA** を再生成する（`dna_hash` で確認、テストあり）。

## 項目

| 項目 | 内容 |
|---|---|
| `instrument_id` | `inst-<素材sha256先頭8桁>-<シードのハッシュ6桁>` |
| `source_type` / `source_name` / `source_hash` | 素材の種類・名前・sha256（バイト列のハッシュは**識別だけ**に使い、音には使わない） |
| `seed` / `engine_version` | DNA シード / `sonova-dna/1.0.0` |
| `pitch_range` | `low` `high` `center`（MIDI ノート）、`root_pc`（主音のピッチクラス） |
| `harmonics` | 16 倍音の強さ `amplitudes`、`inharmonicity`、高次倍音の減衰 `damping`、`brightness` |
| `attack` `decay` `sustain` `release` | エンベロープ（秒 / レベル） |
| `resonance` | 共鳴しやすさ `amount`、フィルターの鋭さ `q`、共鳴の残響 `ring` |
| `noise` | 打撃ノイズの量・色・長さ |
| `modulation` | FM の周波数比と深さ、ビブラートの速さと深さ |
| `filter` | カットオフ（基音の倍数）、フィルター・エンベロープ量 |
| `rhythm` | ユークリッドリズム `E(pulses, steps)`、回転、速度倍率 |
| `pan` | 定位 |
| `interaction_rules` | 働きかけの強さ `emission`、反応しやすさ `sensitivity`、主題を覚える長さ `memory_length`、反応ルール `responses[]` |
| `mapping` | **どの特徴がどのパラメータをどう変えたか**の対応表（パラメータ・値・特徴名・理由） |
| `dna_hash` | `instrument_id` と `dna_hash` 以外の内容の正規化 JSON ハッシュ |

人間による調整（INSTRUMENT LAB のスライダー）は DNA を書き換えず、プロジェクトの `overrides` として別に保存する。

## 写像の考え方（PHOTO INSTRUMENT）

| 素材の性質 | 音への写像 | 理由 |
|---|---|---|
| 空間周波数の 16 帯域 | 16 倍音の強さ | 画像の「模様の細かさの分布」を「音の倍音の分布」としてそのまま使う |
| 縦エッジ / 横エッジの比 | 奇数 / 偶数倍音の偏り | 柱のような縦構造 → 矩形波的 |
| エッジの鋭さ | 速い立ち上がり、非調和性（鐘・板） | 硬い素材の打撃 |
| 細かな粗さ（Laplacian） | 打撃ノイズ、リズムの発音数 | 木目・粒 |
| 反復構造（自己相関） | 共鳴の量・Q・残響、反復周期 → ビブラート速度 → テンポ | 規則的な構造は共鳴する |
| 縦横両方の格子 | 減衰が長い | 建物の格子 |
| 平均輝度 + 空間周波数の重心 | 音域 | 明るく細かい → 高い |
| コントラスト | 音域の幅、持続の短さ | |
| 色相 | 主音（色相環を五度圏に配置）。無彩色なら反復周期と輝度から | |
| 彩度・色の豊かさ | FM の深さと比、音色変化への反応 | |
| 色相の集中 | ビブラートの少なさ、協和への引き寄せ | |
| 明るさの左右位置 | 定位 | |

反応ルールの選び方（`interaction_rules.responses`）: 5 種類の効果それぞれに特徴から親和度を計算し、上位 2 つと、最上位の 55% 以上のものを採用する。

| 効果 | 親和度を上げる特徴 | 何が起きるか | 反応する相手のイベント |
|---|---|---|---|
| `resonate` | 反復の強さ、無彩色 | 相手の音高（またはその 5 度上）で共鳴音を鳴らす | 発音 |
| `timbre` | 彩度、色の豊かさ | 相手の旋律が上がれば明るく、下がれば暗く音色が変わる | 発音・共鳴 |
| `rhythm` | 不規則な方向のエッジ × 粗さ | 自分のユークリッドリズムのパルス数か回転を変える | 他の楽器の変化 |
| `entrain` | 滑らかな明暗 | 相手の 1 拍後に自分の発音が来るよう回転する | 発音 |
| `attract` | 色相の集中 | 次の音を相手の音と協和する音程（3度・5度・8度）にする | 発音・共鳴 |

全パラメータの対応は各 DNA の `mapping` と [experiments/REPORT.md](../experiments/REPORT.md) を参照。
