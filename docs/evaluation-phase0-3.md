## C. 音楽評価

人間はまだ誰も聴いていない。Claude Code は音を聴けないので、以下は**測定値と生成ログから言えること**に限る。「もう一度聴きたいか」は Yuji さんが聴いて判断する必要がある。

| 問い | 測定から言えること | 判定 |
|---|---|---|
| 素材ごとに異なる音が生まれるか | 試聴音のスペクトル重心: bark 3.8kHz（明るい打撃音、ノイズ多め）、tower 2.1kHz（倍音の長い響き）、sunset 0.14kHz（暗いパッド）。Attack は 8ms / 5ms / 670ms | ✅ はっきり違う |
| 音の変化に素材の構造が反映されるか | 役割（リズム / 共鳴 / 音色変化）はコードに書かず、エッジの不規則さ・格子の反復・彩度から決まった。倍音の強さは画像の空間スペクトルをそのまま写したもの | ✅ 説明可能 |
| 楽器同士の相互作用が聴き取れるか | 1 曲あたり共鳴 11〜20 回、変化 27〜37 回、深さ 3 の連鎖が複数（例: 木の発音 → 塔の共鳴 → 夕焼けの音色 → 木のリズム変化）。共鳴は塔の音として必ず聴こえる。**ただし音色変化は sunset（重心 140Hz の暗いパッド）に起きることが多く、明るい bark の下に隠れて聴き取りにくい可能性が高い** | △ 共鳴は聴こえるはず、音色変化は要確認 |
| 予想外の音楽的瞬間があるか | 「塔は最初は鳴らず、木の音に共鳴して目覚める」「TIDE で 2 度の満ち引き」はログ上で確認できる。旋律はスケール上のランダムウォーク + 主題記憶なので、メロディとしての印象は弱いと予想 | ? 聴いて判断 |
| もう一度聴きたいか | 未評価 | ? |

### 次に改善したい点（Phase 5 の前に）

1. sunset の帯域が低すぎてミックスで埋もれる → 音色変化を聴こえる帯域（フィルター開閉）で表現する。
2. 旋律の主題性 → 主題記憶を「変奏」として扱い、共鳴で返ってきた音高を次の主題に取り込む。
3. bark の高域ノイズ（重心 3.8kHz）が耳に痛い可能性 → ノイズ帯域の上限を下げる。
4. `attract`（協和への引き寄せ）ルールを持つ楽器が今回の 3 素材には生まれなかった。色相の集中した素材で検証する。
