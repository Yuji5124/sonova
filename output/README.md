# output/

生成物の置き場所（Git 管理外）。`npm run phase1` / `npm run phase2` で再生成できる。

- `phase1/<name>.instrument.wav` — 楽器の試聴音 (6 秒)
- `phase2/SONOVA-EXP-000N.wav|.mid` — 30 秒の実験
- `lab/` — SONOVA LAB から SOUNDVAULT へ保存した WAV の原本
- `soundvault-backups/` — 登録前の SOUNDVAULT JSON のバックアップ
- `lab-screens/`, `soundvault-ui.png` — ブラウザ検証のスクリーンショット
