# Phase 2 評価メモ — 4 つの実験 (試聴前の判断材料)

**最初に正直に**: この制作環境の私 (Claude) は音を**耳で聴けない**。以下は、楽譜の設計、測定値 (`REPORT.md`)、スペクトログラムによる確認からの判断で、「もう一度聴きたいか」は判定していない。**採否は試聴で決めてほしい**。下の「聴くポイント」はそのためのもの。

## 技術的な確認 (済)

- 4 本とも 48 kHz / 24-bit WAV、MP3 256 kbps、楽器ごとのステム + ホールの返り。ピーク −1〜−4 dBFS、クリップなし、-18 LUFS にそろえた (ダイナミクスは潰していない: LRA 3〜20 LU)
- 2 回レンダリングして同じ結果 (乱数はすべてシード付き)
- スペクトログラムで、設計した出来事 (電子の入り 8 秒、総休止 9 秒・23.5 秒、受け渡し 15 秒・20 秒) が音に現れていることを確認
- VSCO-2-CE のファイル名が実音より 1 オクターブ低いことを測定で見つけ、修正済み (修正前は全楽器が 1 オクターブ低く鳴っていた)
- EXP-D の音色分析は、最初「C3 として」別の高さのサンプル (B2) を分析していた誤りを見つけて修正 (倍音の重心 1.97 → 4.68×f0)

## 第三の音楽現象 (問い 5) の候補

- **A**: 3 対 4 の合成リズム (密度 1.55 倍) と、D minor と F♯ lydian のベルの重なりでできる「どちらの調でもない響き」
- **C**: 総休止の瞬間。2 つの音楽が同時に止まると、ホールの残響だけが一つの音として残る
- **D**: 19–27 秒、電子の打撃と弦の打撃が同じ時刻で鳴る区間 — 「電子でも弦でもない打撃音」。前半の、チェロと加算合成の双子がわずかにずれて重なるうなり

## 聴くポイント (採否の判断のために)

1. A: 2 秒ごとの着地が気持ちいいか、それとも機械的か。ベルの調 (F♯) がオーケストラ (D minor) と喧嘩して聞こえるか、浮遊して聞こえるか
2. B: 9–18 秒で、電子の旋律がオーケストラの動機の「変身」に聞こえるか、別の旋律に聞こえるか
3. C: 9 秒と 23.5 秒の「同時に止まる」瞬間で、2 つが一つの音楽に聞こえるか
4. D: 何秒くらいで「もうチェロではない」と感じるか。後半、どこから弦になったか分かるか

## 推奨 (試聴で覆してよい)

Phase 3 の 2 つの試作には **C (強弱の橋)** と **A (周期の橋)** を推す。最重要指示「和声が一致しなくても一つの音楽として成立する条件」に、測定上いちばんはっきり答えているのがこの 2 つ (調の類似 0.10・0.18 のまま、強弱の相関 0.77・0.74)。
B の動機と D の音色変形は捨てずに、試作の中の素材として使う (完成曲では ORIGIN の動機 = B、TRANSFORMATION = D が必要になる)。

- 試作 1「COLLISION」(40 秒): A の 3/4 対 4/4・2 秒周期 + C の共通の緊張曲線と総休止。D minor と F♯ のまま頂点まで
- 試作 2「TRANSFORMATION」(40 秒): D の音色変形で ORIGIN の動機 (B) をオーケストラから電子へ渡し、電子のリズムを弦とティンパニが受け取る
